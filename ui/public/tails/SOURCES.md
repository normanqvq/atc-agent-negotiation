# Airline tail logos

From Wikimedia Commons. Each file page lists the image as public domain (too simple for copyright) and marks it as a trademark of the airline. Used in the demo only to show which real airline flew each 2015 DOT flight.

| File | Source | Change |
|---|---|---|
| delta.svg | https://commons.wikimedia.org/wiki/File:Delta_Air_Lines_2007_symbol.svg | none |
| southwest-heart.svg | https://commons.wikimedia.org/wiki/File:Southwest_Airlines_logo_2014.svg | cropped to the heart, wordmark removed |
| usairways-flag.svg | https://commons.wikimedia.org/wiki/File:US_Airways_Logo_2011.svg | cropped to the flag, wordmark removed |

Atlantic Southeast (EV) and SkyWest (OO) flew into ATL as Delta Connection in 2015, so they show the Delta symbol.
American (AA) and Spirit (NK) have no symbol-only file on Commons; they keep the plain colour fin.
